Quarto

Quarto is an open-source scientific and technical publishing system.

  • Windows
  • MacOS
  • Linux / WSL

You can download and install Quarto from the Quarto official website. Note for this workshop you do not need to download the "Quarto CLI" in Step 1 on the Quarto webpage, as we will be using a different Command Line Interface (CLI). Rather, download the Quarto installer under the Windows with a file name similar to quarto-1.8.27-win.msi. Run the installer with all the default settings.
